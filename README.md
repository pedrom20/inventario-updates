# inventario-updates

Repositório público, sem código-fonte — só aloja os pacotes de
atualização OTA (over-the-air) da app Android "Inventário Informático"
(CM Odemira), publicados por `frontend/scripts/publish-ota-update.sh`
no repositório principal (privado): https://github.com/pedrom20/Inventario

Existe à parte do repositório principal porque o telemóvel precisa de
descarregar os pacotes sem autenticação — um repositório privado exige
sempre login para aceder aos ficheiros de uma Release.

Não editar nada aqui à mão — `latest.json` e as Releases são geridos
pelo script de publicação.
